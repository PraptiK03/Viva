# Manage Viva Glint experiences in the Microsoft 365 admin center

As an organization with multiple Microsoft Viva Glint experiences in one tenant, manage licenses, service admins, and other settings for each experience in the Microsoft 365 admin center. 

> [!IMPORTANT]
> Single tenants with multiple Viva Glint experiences are currently supported for customers migrating from LinkedIn Glint only.

> [!NOTE]
> To manage Viva Glint experiences in the Microsoft 365 admin center, users need to be members of the [Viva Glint Tenant Administrator role](/entra/identity/role-based-access-control/permissions-reference#viva-glint-tenant-administrator), the [Microsoft 365 global admin role](/entra/identity/role-based-access-control/permissions-reference#global-administrator), or the [License Administrator role](/entra/identity/role-based-access-control/permissions-reference#license-administrator). 

1. Go to the [Microsoft 365 admin center](https://admin.microsoft.com/adminportal/home?#/homepage).
2. In the menu on the left, expand **Settings** and select **Viva**.
3. Select **Viva Glint **and then choose **Manage Viva Glint experiences**.

   :::image type="content" source="../../media/glint/setup/mac-glint-experiences.png" alt-text="Screenshot of multiple Viva Glint experiences in the Microsoft 365 admin center.":::
   
5. Select a company to edit or view the:
  - **General tab**: Basic company information and [Viva Glint license](glint-order-teams.md) management.
  - **Service admins tab**: Manage [Viva Glint service admins](post-provisioning-next-steps.md#assign-viva-glint-service-admins) who manage the Viva Glint app.
  - **Settings tab**: Learn how to manage [attribute visibility](update-attributes.md#update-custom-attribute-visibility) in the Viva Glint app.

> [!NOTE]
> Users in the Microsoft 365 [License Administrator role](/entra/identity/role-based-access-control/permissions-reference#license-administrator) only have access to the General tab for each Viva Glint experience.
