# Viva Glint supported languages

Microsoft Viva Glint supports 60+ languages for users' survey and dashboard experiences. Use the "Language code (required format)" column in the following table to include valid values when [setting up language attributes and managing translations](#set-up-language-attributes-and-manage-translations).
