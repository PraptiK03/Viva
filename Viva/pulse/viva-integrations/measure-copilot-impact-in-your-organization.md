# Measure Microsoft 365 Copilot impact with Viva Pulse

The [Microsoft Copilot Dashboard](/viva/insights/org-team-insights/copilot-dashboard) helps organizations maximize the value of Microsoft 365 Copilot by providing actionable insights to help organizations get ready to deploy, drive adoption, and measure the impact of Copilot.

Viva Pulse integrates with the Microsoft Copilot Dashboard to capture sentiment data, helping leaders measure Microsoft 365 Copilot's effectiveness. Leaders and admins can use a research-backed template to send surveys and gather team feedback directly from the dashboard or within Viva Pulse.

To integrate Pulse survey results into the Copilot Dashboard, you must have at least one of the following subscription licenses:

* Viva Suite
* Viva Workplace Analytics and Employee Feedback
* Microsoft 365 Copilot (As part of this subscription, Viva Pulse survey results for the Copilot impact template are automatically shared to the Microsoft Copilot Dashboard).

### Capture sentiment about Copilot from the Microsoft Copilot Dashboard

If you have access to the Microsoft Copilot Dashboard you can launch a Pulse survey to capture feedback from your teams. This feedback is mapped to workplace patterns data collected by Viva Insights.

1. Access the [Microsoft Copilot Dashboard](/viva/insights/org-team-insights/copilot-dashboard).
2. Select the **Sentiment** tab in the Microsoft Copilot Dashboard.
3. Scroll to the bottom of the page and select the **Start new Pulse survey** in the **Employee sentiment about Copilot** section.

### Capture sentiment about Copilot from Viva Pulse

If you don’t have access to the Microsoft Copilot Dashboard, you can launch a Pulse survey within Viva Pulse.
1. Access the Copilot impact template in Viva Pulse either on the web or from within Teams.
    * To access the template on the web, go to the [Microsoft 365 Copilot Impact survey](https://go.microsoft.com/fwlink/?linkid=2259628).
    * To access the template in the Teams app, do the following:
        1. Open Viva Pulse.
        2. On the home page, select **Browse all templates** in the **Get started by asking for feedback on…** section.
        3. Scroll to **For managers and leaders** and select **Microsoft 365 Copilot impact**.

2. Customize the Copilot impact template in Viva Pulse

    The Copilot impact questions are read-only to preserve accurate relationships between sentiment data collected from Viva Pulse and workplace patterns data collected by Viva Insights. Because of this, four core questions in the template can't be deleted. However, you can customize other aspects of the template. You can:

    * Add questions from the Microsoft Copilot impact topic in the question library.
    * Delete questions added in from the Microsoft Copilot impact topic in the question library.
    * *Reorder questions in the template with the up and down arrows on each question.
    * Click Next to finalize your Pulse and add or remove survey recipients as needed.
    * Update the survey end date and time as needed. The default length of a Pulse is 7 days.
    * Add an optional personal note that will be shown to survey recipients when they receive a notification about your Pulse.

3. Select **Next** to send the Copilot impact Pulse.

### Review the reports in the Microsoft Copilot Dashboard and in Viva Pulse

When the Pulse closes, you’ll get a notification to review the results. If you created the Pulse from within the Microsoft Copilot Dashboard, the notification includes a link to the Microsoft Copilot Dashboard and a link to the Pulse report to view the data in more detail.

If you did not create the Pulse from the Microsoft Copilot Dashboard, then the notification will only have a link to the Pulse report to review the sentiment data in more detail.
